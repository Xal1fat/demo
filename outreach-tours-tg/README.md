# Тури · Telegram

Дошка для аутрічу в Telegram. Сторінка: https://xal1fat.github.io/outreach-tours-tg/

## Що всередині

- `index.html` — дошка: фільтри (без сайту / з сайтом / активні / свіжі), пошук, кнопки «Відкрити канал», «Написати @адміну», копіювання тексту, статуси.
- `data.js` — канали й тексти.
- `scrape/` — скрипти, якими це зібрано.

## Як зібрано

Telegram віддає **публічне прев'ю каналу без входу**: `https://t.me/s/<username>`. Там є назва, опис, кількість підписників, дата останнього поста й посилання з опису.

1. `scrape/discover_lyzem.py` — пошук каналів через lyzem.com + парсинг `t.me/s/`.
2. `scrape/build_data.py` — фільтри й генерація `data.js`.

Що фільтрується:
- останній пост старший за 2 місяці → канал «тихий», не беремо;
- немає туристичних слів в описі → не беремо;
- новинні/міські канали, знайомства, робота → не беремо;
- сайт визначається так: якщо в описі є посилання не на соцмережу — «є сайт».

## Обмеження

- Пошукові індекси (Brave, DDG) швидко віддають капчу при серії запитів — тому пул збирається частинами.
- Каталоги (lyzem, tgstat) сильно застарілі: більшість каналів у видачі — 2021–2023 років.
- Тому краще за все працює **ручне додавання**: побачив канал у рекомендаціях Telegram — додав нік у `data.js`.
- Кількість підписників і опис можуть відставати на кілька тижнів.

## Як додати канал

```js
{"u":"username","t":"Назва каналу","d":"опис","s":1200,"l":"2026-10-29T10:00:00+00:00",
 "site":"no","ad":"admin_username","m":"Текст першого повідомлення."}
```

`site` — `"no"` або `"yes"`. `ad` — нік адміна без @, якщо знаєш.

## Правила відправки

1. У Telegram немає «запитів» — повідомлення падає в інбокс одразу. Це плюс і причина бути обережним.
2. 20–30 нових діалогів на день максимум; новий акаунт — 10–15.
3. Спершу коментар під постом по суті, потім особисте повідомлення.
4. Посилання — тільки після «так». Скрини можна прикріплювати одразу: у Telegram це нормально.
5. Один follow-up через 3–4 дні. Після «ні» — не писати.
