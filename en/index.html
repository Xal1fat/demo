02 / casebeauty salon

What actually works in this project

Demo data — invented name, addresses and prices. The backend is real: I hit the live API before publishing this page.

shipped

  • Booking form: service, specialist, date and time. Validation runs on the server.
  • Request is stored in Supabase. Verified with a live API call — response “ok”.
  • Owner gets a Telegram message. If Telegram fails, the request is still stored.
  • Password-protected admin: list, search, filters, status changes.
  • Responsive from 320 px, lightbox gallery, 9 sections.

not shipped

  • Slot availability — the schedule is illustrative.
  • Online payment — booking without prepayment.
  • Real reviews — demo content, marked as such.

adaptable

Colours, logo, name, services and prices, specialists, photos, contacts, opening hours, copy.
