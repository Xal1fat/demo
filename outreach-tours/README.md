# Тури · аутріч

Дошка для холодних повідомлень авторським турам і туроператорам.
Сторінка: https://xal1fat.github.io/outreach-tours/

## Що всередині

- `index.html` — дошка: пошук, фільтри, кнопки Instagram / Telegram, копіювання тексту, статуси «Написав / Відповів» (зберігаються в localStorage, тобто в цьому браузері).
- `data.js` — профілі й тексти. Правиться руками, без збірки.

## Звідки дані

Instagram закритий для ботів: анонімно віддає тільку стіну логіну, API — `require_login`, дзеркала (imginn, picnob, dumpor) — капчу.
Тому профілі зібрані з **пошукової видачі**: Brave і DuckDuckGo індексують сторінки профілів разом із біо, кількістю підписників і постів.
Brave стабільніший (DDG швидко віддає капчу), запит той самий — `site:instagram.com "…"`.

Робочі запити (можна повторити й добрати ще):

```
site:instagram.com "авторські тури"
site:instagram.com "групові тури"
site:instagram.com "тури" "Ісландія"
site:instagram.com "тури" "Карпати"
site:instagram.com "фототури"
site:instagram.com "туроператор" Україна
```

Обмеження методу: біо може відставати на кілька тижнів, а наявність сайту з видачі не видно.
Тому `site` в `data.js` — це **припущення**:

| значення | що означає |
|---|---|
| `null` | сайту не знайдено (домену немає в біо, хендл без домену) |
| `""` | невідомо, треба глянути профіль |
| `"https://…"` | сайт є (або є другий бренд із сайтом) |

Перед відправкою — 10 секунд на перевірку: відкрити профіль і подивитися шапку. Якщо сайт є, а в картці «без сайту» — виправ `site` у `data.js`.

## Як додати профіль

```js
{
  h: "handle",                    // нік без @
  n: "Назва · напрямки",          // як показувати на дошці
  b: "біо одним рядком",          // що видно в профілі
  f: 12000, p: 340,               // підписники, пости
  site: null, tg: "",             // сайт (null / "" / url), телеграм без @
  m: `Текст першого повідомлення.`
}
```

Telegram можна не вписувати вручну: на дошці кнопка «＋ Telegram» попросить нік і запамʼятає його.

## Як писати (коротко)

1. 4–5 нових діалогів на день, не 20.
2. Спершу відповідь на сторис або коментар — це кладе переписку в інбокс, а не в «Запити».
3. Посилання — тільки після «так». У першому повідомленні його немає навмисно.
4. Один follow-up через 3–4 дні, текстом, без посилання. Більше — не писати.
5. Текст у картці персоналізований по біо (дати, напрямки, аудиторія). Якщо правиш — не роби його однаковим для всіх: саме однаковість і вбиває доставку.
